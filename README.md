# TeraBox Video Hub

Mobile-first static landing page එකක් ලෙස නිර්මාණය කළ GitHub Pages project එකකි.

## Architecture

මෙම repository එක භාවිතා කරන්නේ:

- Semantic HTML5
- Responsive CSS
- Vanilla JavaScript
- Web App Manifest
- GitHub Pages Actions deployment
- Dependency-free static architecture

Jekyll, Ruby, Astro, Node build process හෝ Cloudflare configuration අවශ්‍ය නොවේ.
